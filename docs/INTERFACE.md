# Interfejs pracowni

Główna ścieżka to pytanie → fragmenty prawa → ewentualne objaśnienie.
Klasyfikacja dziedziny jest pomocniczym narzędziem. Niski wynik klasyfikatora
nie blokuje formularza odpowiedzi ze źródeł.

Przykłady wypełniają formularz bez uruchamiania modelu i bez nadpisywania pytania.
Pierwszy znaleziony fragment jest rozwinięty. Podanie daty sprawy ma jawnie
opisany wpływ na objaśnienia. Czas oczekiwania pokazuje czas rzeczywisty,
bez fikcyjnego procentu postępu. Statystyki nie udają oceny poprawności prawnej.

Ruch wskazuje zmianę panelu lub wyniku: 200 ms, opacity/transform, łagodne
wyhamowanie. Nawigacja klawiaturą nie dodaje animacji przejścia. Animacje wejścia
w nagłówku są ograniczone do większych ekranów; preferencja `prefers-reduced-motion`
wyłącza ruch. Efekty hover działają wyłącznie przy odpowiednim urządzeniu wskazującym.

Projekt korzysta z zasad [Emila Kowalskiego](https://github.com/emilkowalski/skills)
i [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design).
Nie wymaga zewnętrznej biblioteki animacji. Materiały sterujące pracą agentów nie
są częścią publicznego repozytorium.
